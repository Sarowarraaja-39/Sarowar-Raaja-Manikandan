# Sarowar Raaja Manikandan — Portfolio

Production build of the React portfolio. All images, fonts, scripts and styles are bundled locally.

## Publish with GitHub Pages

In repository **Settings → Pages**, choose **Deploy from a branch**, select **gh-pages**, choose **/ (root)** and click **Save**.

Once GitHub finishes publishing, the public website is:

https://sarowarraaja-39.github.io/Sarowar-Raaja-Manikandan/

This branch contains the compiled website. Editable React source remains on the `main` branch in `react-source/`. Retain `ASSET_NOTES.md` and `third-party-licenses/` with the build.
